## Hi, I'm Faizan 👋

I'm a **full-stack developer** who builds web apps, dashboards and the integrations that connect them. I work mostly with **Next.js and TypeScript** on the frontend and **Laravel and Node.js** on the backend.

- 🛠️ I build business tools: admin panels, team dashboards, document and file management systems
- 🔌 I connect platforms: CRM and website sync (HubSpot ↔ Wix), OAuth flows, webhooks, ClickUp and Google APIs
- 🌐 I ship production websites for clients on Vercel
- ✅ I write tested code: Pest for Laravel, Vitest for TypeScript
